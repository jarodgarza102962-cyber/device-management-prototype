# 电脑/触控平板端：新增设备记录功能需求说明

## 1. 功能概述与进入方式
外部系统通过 URL 参数或跨域消息传入**设备名称**与**记录类型**（如 `recordType=use`），即可直接打开【新增设备记录】弹窗工作台。
- **界面适配规范**：适配 **1280×800 触摸板（触屏工控机/平板 Pad）**标准触控操作规范，控件具备大触控热区与防误触间距。
- 🖥️ **在线交互预览**：[https://jarodgarza102962-cyber.github.io/device-management-prototype/](https://jarodgarza102962-cyber.github.io/device-management-prototype/)

## 2. 核心功能与交互规则

### 2.1 弹窗顶部栏与关闭
1. **弹窗主标题**：居中固定为【新增记录】，不随设备或记录类型变化；
2. **页面关闭**：支持点击右上角关闭按钮或底栏【取消】按钮，二次确认后向外部系统发送关闭回调并安全销毁弹层。

### 2.2 左侧：待填报设备选择区
1. **工具栏极简规范**：
   - 去除非业务必需的设备类型下拉筛选与模糊搜索输入框，界面更加纯粹高效；
   - 顶部工具栏直接展示【全选】复选框、已选台数小计（如 `已选 2 台`）以及快捷【清空】操作；支持一键清空或反选卡片至 0 台。
2. **设备卡片 5 大核心信息规范**：
   - 每张卡片完整规范地展示 5 项核心台账信息：
     - **设备名称**（加粗黑体 15px）；
     - **固定资产编号**（标准资产编码，如 `FA-2025-0016`）；
     - **设备编号**（科室物理编号，如 `PCR-CLEAN-301`）；
     - **所属工作台**（科室专属台位，如 `分子生物学工作台`）；
     - **设备类型**（分类标准，如 `超净工作台`）。
3. **单条录入与批量模式选择规则**：
   - **单条录入单选直切**：在【单条录入】模式下，系统只支持选择一台设备；点击任意卡片直接平滑切换为目标设备并展开其表单，**彻底去除跨模板拦截 Toast 提示与阻断**；
   - **一键批量多选联动**：在【一键批量】模式下，支持勾选多台同类设备进行合并批量展示与一键提交。

---

### 2.3 右侧：记录类型横幅、动态表单与未选设备极简交互

#### 2.3.1 顶部记录类型横幅与填报频次展示
位于右侧表单滚动区正上方通栏横幅，向操作人员清晰告知当前记录模板性质与填报周期规范：
1. **记录类型标题**：始终展示纯粹的**记录模板类型名称**（如“运行”、“使用记录”、“维护记录”、“校准记录”等），随外部系统传入的类型参数保持一致，**绝对不拼接显示“xx设备使用记录”，未选中设备时也不会显示“未选择设备”**；
2. **填报频次提示**：紧跟在标题右侧，带提示图标，动态展示该设备绑定的标准填报周期频次（如“使用时需要”、“每日一次”、“每周一次”、“每月一次”、“每批次一次”等），为操作人提供填报规范依据；
3. **未选中设备联动**：当左侧未勾选任何设备（0 台）时，顶部标题依旧稳定展示当前的记录模板类型名称，右侧填报频次图标及文本自动隐藏不展示。

#### 2.3.2 未选中设备时的极简空状态（无表单、无底栏按钮）
当左侧已选设备为 0 台时（包括初始未选、批量清空或反选至 0 台）：
1. **表单区域**：不展示任何表单组件，仅在屏幕正中央居中展示一行干净文本：**`请选择需要填报记录的设备`**；
2. **底部操作栏**：**整栏隐藏，不展示任何按钮（无【确定】与【取消】按钮展示）**，视觉纯粹零干扰，彻底杜绝未选设备时的误提交顾虑。

#### 2.3.3 选中设备后的动态唤醒与渲染
一旦在左侧勾选设备（已选台数 $\ge 1$）：
1. **横幅恢复频次**：标题右侧立即唤出该设备对应的填报频次；
2. **动态表单渲染**：根据所选设备专属模板即刻加载两栏布局表单组件；
3. **底栏唤出**：底部操作按钮栏即刻完整浮现【确定】与【取消】按钮。

#### 2.3.4 【单条录入】与【一键批量】全两栏布局与真机组件规范
系统在横幅右侧提供模式切换分段控制器（**【单条录入】** 与 **【一键批量】**），**页面初始化默认选中【一键批量】Tab**，两种模式统一采用**两栏布局（2-Column Grid）**：
1. **单条录入两栏真机组件规范**：
   - **两栏排布**：字段按业务逻辑分为左右两栏，充分利用宽屏横向空间；
   - **必填红色星号**：所有必填项标签前面均带有显眼的红色星号（`* `）；
   - **扁平输入框**：文本框、日期框、数字框均采用极简无厚边框设计，内容右侧带浅灰圆形清除叉（`×`）；
   - **圆形原生单选**：单选组采用真机原生圆形按钮（选中为蓝底白勾），选项文本紧随圆圈无胶囊卡片背景；行末靠右对齐展示**蓝色文字带下划线**的【清空】操作；
   - **多选展示**：右侧展示当前选中值文本，最右端带向右折叠箭头（`>`）；
   - **界面极简**：去除非业务必须的顶部文字标签说明条与复制/粘贴按钮，直接沉浸呈现纯粹的运行参数表单项；
2. **【一键批量】两栏只读看板规范（默认激活态）**：
   - **两栏只读清单**：已选设备的组件与对应合规默认值按两栏排版展示，纯只读无输入框；
   - **为空字段直接置空**：默认值为空的字段直接留白，不展示“为空”字样；
   - **去除多余装饰**：不展示状态徽标、无多余大横幅，字段无彩色高亮；
   - **纯文本底栏按钮**：底栏按钮无图标，纯文本展示为 **【批量保存（共N台）】**。
3. **模式切换设备联动收敛规则**：
   - 当从【一键批量】切换回【单条录入】时，若此前处于多选状态，系统自动收敛为**仅选中最前面的一个设备**，杜绝多选残留并立即联动刷新右侧精细两栏表单。

---

### 2.4 底部保存与外部回调（三步校验流水线）
点击底栏【确定】按钮触发标准化保存流水线：
1. **步骤 1（完整性校验）**：核验表单各项必填项（时间、人员、测定数值等），缺失时高亮警示；
2. **步骤 2（批量生成记录流水）**：遍历已选中的 $N$ 台设备，调用后端批量写入接口，为每台设备分别生成一条具有独立主键的历史记录台账；
3. **步骤 3（反馈与关闭回调）**：
   - 屏幕中央弹出成功提示：`保存成功！已为所选的 N 台设备写入历史台账。`；
   - 向外部宿主系统发送成功回调事件（携带保存台数、记录类型及设备 ID 列表），通知外部系统关闭弹窗并刷新数据。
