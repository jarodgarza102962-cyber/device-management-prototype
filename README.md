# 电脑端【新增设备记录】需求规格说明书

## 1. 功能概述
- **设计稿在线预览**：https://jarodgarza102962-cyber.github.io/device-management-prototype/
- **调用机制**：外部系统通过 URL 参数传入设备名称与记录类型（如设备运行、使用记录等），即可直接打开【新增设备记录】弹窗。系统自动联动定位设备并初始化对应的记录模板。

---

## 2. 功能与交互说明

### 2.1 弹窗标题与关闭
- **弹窗标题**：固定为【新增记录】，不随设备或记录类型变化。
- **页面关闭**：支持点击右上角关闭按钮或底栏【取消】按钮，二次确认后向外部系统发送关闭回调并销毁弹窗。

### 2.2 左侧：待填报设备选择区
- **设备卡片信息展示**：
  每张卡片统一展示 5 项信息：
  1. 设备名称
  2. 所属工作台（位于第二行醒目展示）
  3. 固定资产编号
  4. 设备编号
  5. 设备类型
- **全选、小计与清空**：
  - 工具栏展示【全选】复选框及已选台数（如 `已选 2 台`）；
  - 提供快捷【清空】操作，点击后一键清空所有已选设备（已选变 0 台）；支持反选卡片至 0 台。
- **设备选择规则**：
  - **单条录入模式**：仅支持单选一台设备，点击任意卡片直接平滑切换为目标设备，无跨模板拦截；
  - **一键批量模式**：支持多选勾选相同记录模板的设备进行批量填报。

### 2.3 右侧：录入与展示区

#### 2.3.1 模式切换与顶部横幅
- **模式切换**：
  - 提供【单条录入】与【一键批量】两个模式切换 Tab，**默认选中【一键批量】**；
  - 模式联动收敛：当从【一键批量】切换回【单条录入】时，系统自动截断仅选中最前面的一个设备，避免多选残留。
- **记录类型标题**：展示当前业务记录类型名称（如“运行”、“使用记录”、“维护记录”）。
- **单条录入周期频次与防重提醒**：
  - 在单条录入模式下，横幅右侧展示当前选中设备的填报频次及当前周期的记录执行状态；
  - 无记录时提示：`频次 · 当天无记录`（根据频次对应“当天/本周/本月/当前”）；
  - 提交成功或已有记录时提示：`频次 · 当天已有 N 条记录`，清晰提醒用户无需重复提交。

#### 2.3.2 未选中设备时
- **触发条件**：当左侧已选设备为 0 台时；
- **展示表现**：
  - 居中展示极简提示：`请选择需要填报记录的设备`；
  - 底部操作栏整栏隐藏，避免误操作。

#### 2.3.3 选中设备后的表单渲染（两栏布局）
- **单条录入模式**：
  - 采用两栏布局呈现当前选中设备的完整录入表单；
  - 支持单选、多选、文本输入、数值填报、日期时间选择等组件；
  - 必填项有必填标识；单选项支持快捷清空。
- **一键批量模式**：
  - 采用两栏布局直观展示所有已选设备的合规默认值看板（只读展示，不可在此编辑修改）；
  - **设备标题栏频次与状态**：在每台设备的卡片标题栏右侧，独立展示该设备的填报频次及记录条数提醒（如 `使用时需要 · 当前无记录` / `使用时需要 · 当前已有 1 条记录`）；
  - 底部确认按钮显示为【批量保存（共 N 台）】。

### 2.4 保存与外部回调
- 点击底栏【确定】/【批量保存】按钮触发校验与提交；
- 校验必填项完整性后，为所选设备批量写入业务记录流水，并实时更新设备的记录条数与状态提醒；
- 保存成功后弹出提示，并向外部系统发送成功回调事件，关闭弹窗。
