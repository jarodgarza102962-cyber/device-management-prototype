# 电脑/触控平板端：新增设备记录功能需求说明

## 1. 功能概述与进入方式
外部系统通过 URL 参数或跨域消息传入**设备名称**与**记录类型**（如 `recordType=use`），即可直接打开【新增设备记录】弹窗工作台。
- **界面适配规范**：适配 **1280×800 触摸板（触屏工控机/平板 Pad）**标准触控操作规范，控件具备大触控热区与防误触间距。
- 🖥️ **在线交互预览**：[https://jarodgarza102962-cyber.github.io/device-management-prototype/](https://jarodgarza102962-cyber.github.io/device-management-prototype/)

## 2. 核心功能与交互规则

### 2.1 弹窗顶部栏与关闭
1. **弹窗主标题**：居中固定为【新增记录】，不随设备或记录类型变化；
2. **页面关闭**：支持点击右上角关闭按钮或底栏【取消】按钮，二次确认后向外部系统发送关闭回调并安全销毁弹层。

### 2.2 左侧：待填报设备选择区
1. **设备筛选**：
   - 第一行提供**设备类型**下拉单选（全部类型、医用低温箱、超净工作台、PCR基因扩增仪等）；
   - 第二行提供**模糊搜索框**，支持按设备名称、设备编号即时过滤卡片。
2. **设备卡片信息展示**：
   - 每张卡片统一垂直展示 4 项信息：**设备名称**、**设备类型**、**固定资产编号**、**设备编号**。
3. **全选、小计与清空**：
   - 工具栏展示【全选】复选框及已选台数（如 `已选 1 台`）；
   - 提供快捷【清空】操作，点击后一键清空所有已选设备（已选变 0 台）；支持反选唯一卡片清空至 0 台。
4. **设备卡片选择与跨模板拦截规则**：
   - **同模板批量填报**：记录模板相同的同类型设备（如低温箱与冷藏箱同为温控模板），支持批量多选合并填报；
   - **跨模板 Toast 拦截**：当已有选中设备时，点击不同记录模板的设备（如已选超净台点击低温箱），系统阻断勾选、触发卡片抖动，并在屏幕中央弹出 Toast 警告：`【当前设备】与【目标设备】记录模板不同，请选择相同记录模板的设备`；
   - **单台专属模板拦截**：若目标模板声明为单台录入（`allowBatch=false`），多选时拦截并弹出 Toast：`当前记录类型仅支持单台设备录入，不支持批量填入`。

---

### 2.3 右侧：记录类型横幅、动态表单与未选设备极简交互

#### 2.3.1 顶部记录类型横幅与填报频次展示
位于右侧表单滚动区正上方通栏横幅，向操作人员清晰告知当前记录模板性质与填报周期规范：
1. **记录类型标题**：始终展示纯粹的**记录模板类型名称**（如“运行”、“使用记录”、“维护记录”、“校准记录”等），随外部系统传入的类型参数保持一致，**绝对不拼接显示“xx设备使用记录”，未选中设备时也不会显示“未选择设备”**；
2. **填报频次提示**：紧跟在标题右侧，带提示图标，动态展示该设备绑定的标准填报周期频次（如“使用时需要”、“每日一次”、“每周一次”、“每月一次”、“每批次一次”等），为操作人提供填报规范依据；
3. **未选中设备联动**：当左侧未勾选任何设备（0 台）时，顶部标题依旧稳定展示当前的记录模板类型名称，右侧填报频次图标及文本自动隐藏不展示。

#### 2.3.2 未选中设备时的极简空状态（无表单、无底栏按钮）
当左侧已选设备为 0 台时（包括初始未选、批量清空或反选至 0 台）：
1. **表单区域**：不展示任何表单组件，仅在屏幕正中央居中展示一行干净文本：**`请选择需要填报记录的设备`**；
2. **附件资料区**：联动隐藏不展示；
3. **底部操作栏**：**整栏隐藏，不展示任何按钮（无【确定】与【取消】按钮展示）**，视觉纯粹零干扰，彻底杜绝未选设备时的误提交顾虑。

#### 2.3.3 选中设备后的动态唤醒与渲染
一旦在左侧勾选设备（已选台数 $\ge 1$）：
1. **横幅恢复频次**：标题右侧立即唤出该设备对应的填报频次；
2. **动态表单渲染**：根据所选设备专属模板即刻加载对应输入组件（单选/多选组右侧均配有快捷【清空】操作）；
3. **附件资料展开**：表单下方展开【附件资料】模块（支持【连接高拍仪】扫查与【选择文件】上传真实业务巡检单、监控纸凭证）；
4. **底栏唤出**：底部操作按钮栏即刻完整浮现【确定】与【取消】按钮。

#### 2.3.4 【单条录入】与【一键批量】双模式切换及纯只读两栏展示规范
为同时满足操作员“对单台设备精细化填报”与“对多台设备直接套用模板组件默认值批量保存”的高频诉求，系统在横幅右侧提供模式切换分段控制器：
1. **切换入口名称**：
   - 包含两个分段选项：**【单条录入】** 与 **【一键批量】**；
   - 默认处于【单条录入】模式；
2. **【单条录入】模式交互**：
   - 针对当前单台聚焦设备展开完整的标准动态表单与附件上传区；
   - 适合需要仔细核对或有特殊测定值的精细录入场景，底部操作按钮为【确定】与【取消】；
3. **【一键批量】模式交互与展示规范**：
   - **去除顶部冗余提示**：无“一键批量新增模式”等大横幅提示，不展示“统一记录时间”、“记录人”等冗余卡片，保持区域极致简洁干净；
   - **两栏只读布局**：批量设备清单卡片内，对应模板中的组件及默认值统一按**两栏（2-Column Grid）**排版展示；
   - **纯只读展示，无可编辑框**：所有字段纯静态文本只读渲染，不提供输入框或可编辑控件；
   - **模板组件与默认值呈现**：清晰呈现该模板的所有业务字段与标准默认值；若字段默认值为空，则明确展示为“为空”；
   - **去除状态标签与装饰提示**：不展示“必填项已加载合规默认值”等状态徽标；
   - **素雅无彩色排版**：字段名称与值均采用中性常规文字展示，不添加彩色高亮，不使用彩色标签或胶囊背景，避免视觉杂乱；
   - **底部按钮规范**：底部保存按钮无图标，纯文本展示为 **【批量保存（共N台）】**（如 `批量保存（共2台）`），点击后一次性将所有已选设备的合规记录写入历史台账。

---

### 2.4 底部保存与外部回调（三步校验流水线）
点击底栏【确定】按钮触发标准化保存流水线：
1. **步骤 1（完整性校验）**：核验表单各项必填项（时间、人员、测定数值等），缺失时高亮警示；
2. **步骤 2（批量生成记录流水）**：遍历已选中的 $N$ 台设备，调用后端批量写入接口，为每台设备分别生成一条具有独立主键的历史记录台账；
3. **步骤 3（反馈与关闭回调）**：
   - 屏幕中央弹出成功提示：`保存成功！已为所选的 N 台设备写入历史台账。`；
   - 向外部宿主系统发送成功回调事件（携带保存台数、记录类型及设备 ID 列表），通知外部系统关闭弹窗并刷新数据。
