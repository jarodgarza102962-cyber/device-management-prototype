# 设备供应商管理需求说明

## 一、 项目背景
为满足病理科对设备供应商的合规性管理（符合 CNAS/ISO 15189 等质量体系标准），需在现有设备系统中建立完善的“设备供应商档案”，并提供灵活且可追溯的“供应商评价”功能，从而全面支持科室对供应商服务质量和临床业务保障能力的动态监控与后期审查。

## 二、 功能总览
1. **基础档案管理**：支持对设备供应商的基础信息、主要联系人以及关联的资质证明文件进行增删改查及日常统一管理。
2. **按需发起评价**：直接选中供应商卡片或列表行，能够调用电子表单引擎便捷发起评价流程。
3. **审批流集成**：评价报表提交结案后，结构化流转至系统统一的“审批中心”进行在线电子走签处理与状态跟踪。

## 三、 详细功能说明

### 3.1 供应商列表与基础信息
页面排版及编辑展示的交互范式整体参照本系统中既有的“试剂耗材-供应商管理”列表及相关编辑详情页面风格。

- **核心字段信息**：
  - 包含供应商名称（必填项）、所属专业组（病理组/免疫组化组/分子组等下拉设定）、联系人、固定/移动连线电话、企业邮箱、工商地址及其他情况备注。
- **资质管理模块（附件形式展示）**：
  - 在供应商基础表单中提供上传控件，支持加载并挂载多个资质附件资料，包括并不限于：营业执照复印件、生产及经营许可证、厂家合规授权书、技术工程师从业资质证明、售前/售后服务承诺方案等。
  - **效期监控逻辑**：挂靠的每一个资质文件均需准确录入有效起止日期；系统后台运算预警。
  - **启用状态及视觉反馈**：摒弃繁复的资质标签告警，列表层级只需要直接标识该供应商是处在流转线上的“已启用”（绿色底边色）或是“已停用”（灰色或红色底色）。
  - **附件数量徽标**：针对上传的附件情况，在供应商名卡上直接展示总的资质数量标签，例如“资质：1”或“资质：3”。
- **功能操作支持**：
  - **【新增】**：人工输入创建一套新的供应商建档名片。
  - **【评价】**：（新增流转动作）列表首要行级操作，排在行按钮最前。
  - **【编辑】**：二次修正基础资料或附件归档更新，排在中间展现。
  - **【删除】**：废除、清理误增且无强关联记录的错漏建档资产，排在行尾。
  - **【数据流转】**：通过顶栏操作支持直接下载模板文件、批量导入及各种数据列表的快速导出动作。
注：每个供应商卡片内的内联操作按钮必须依次固定为：**评价、编辑、删除**。

### 3.2 供应商评价记录关联管理（核心业务逻辑）
- **全新的触发与前置交互逻辑**：
  - 位于卡片操作栏，点击“评价(x)”按钮后，不再直接进入硬性填报流程，而是**首先唤起“评价记录展示大弹窗”**（针对视觉动线，弹窗需加宽加大，标题置于中部居中显示）。
  - **评价记录列表区域**：在弹窗面板内部，使用数据表格形式汇总展现该企业的历史评定履历；表格需清晰暴露可借览的列名规则：**“序号、标题、内容预览、发起时间、审批状态、发起人”**。
  - **查看表单详情**：强化穿透体验，支持表格行级交互。用户**双击列表行**时，可从页面最右侧额外唤出专职的只读信息侧框（Side Drawer 表单侧框详情页），供深度查阅历史评价表单的全量明细数据快照。
  - **新增发起动作**：在此核心弹窗顶部右侧区设立 **【发起表单】** 按键。点击触发时，横向调用后台通用的“智能审批中心”服务来真正新建电子评价填报与流转表单。
- **基础数据预填机制**：
  - 点击“发起表单”进行新增时，引擎即刻抓取当前所选择商家的主名片数据并静默锁死进新拉起的表单组件中。
  - 同步调用后端装配的【供应商评价表】呈现。
- **表单详情内容建议（应提供自适应与动态电子预配能力）**：

| 核定维度 | 具体评价业务项 | 记录形式 | 分值权重结构 |
| :--- | :--- | :--- | :--- |
| **资质合规** | 检查当前企业证件及合规资质是否稳妥处在有效周期内 | 单选选项（是/否） | **强制勾选项** |
| **技术支持能力** | 仪器出现偶发或重大故障时的应急响应速度及上门抢修成功率时效 | 评分工具（1-5颗星） | 30% 分区 |
| **临床培训服务** | 产品投用期的临床跟台带教及规范标准的下发辅导表现质量 | 评分工具（1-5颗星） | 20% 分区 |
| **维保配件供应** | 原厂核心零件、日常消耗品备件下发时效及供货链库房充足率 | 评分工具（1-5颗星） | 20% 分区 |
| **综评结论建议** | 收官对此次审核周期做出关键定性：是否提请科室决策层延续续签 | 终结结论（合格/不合格）| 30% 分区 |
| **发起评价事由** | 阐明启动评价诱因：年底综合评价反馈/某重大维保事故后考评/新商考察期满评价 | 文本段/规范下拉选择| - |

### 3.3 审批走交流程集成
- **推卷动作**：表单各项必填评分点齐备后，评价发起人触发“提交”，单据转配发入该院统一的综合【审批中心】流转等待审阅审核。
- **状态反向反馈监控**：
  - **互斥及待审批锁定防呆**：如果判定该供应商当前正好存有一条“正在流转及审批尚未完结”的评级票据，卡片的辅助信息区会直观追加“评价中”状态标签，且最右侧的统一评价入口“评价(x)”依然全时可见可点击；但内层详情弹窗中的【+ 新增评价记录】执行主钮应当自动步入防重置灰锁定，用明文提示进行拦截，彻底阻断同一周期的盲目重投打乱内控流程。
  - **正向截结（已通过）**：审批链各级流完全结序，引擎层级将该评价电子单快照沉浮合并转化为不可更改的 PDF 文件，稳固并挂载收纳于对应供应商侧“历史记录”页卡下长久供参阅。
  - **逆向回调（已驳回）**：单据如被退单驳回，起草人第一时间收到醒目红点级提醒站内信函（支持点击超跳），支持点开二次更新并重走提审轨道。

## 四、 页面交互与原型规则定义
- **快捷过滤查询区设计**：列表层上方预留出复合检索空间地带区域，支持使用“供应商公司名称及对应首字母拼音简码”快速进行模糊匹配搜寻，并自带以所属“专业小组”和“是否含有失效过期资质（资质状态）”维度的交叉条件过滤机制。
- **交互级操作凸显**：除了基础维护用的「编辑✎」、「删除✘」列向基础文本钮，需额外引入或拔高【评价】按钮的关注视野阶层（如图形加粗外溢等）。
- **逻辑强校验灰置状态防呆**：界面只服务单次流评估逻辑，多选框选定超出1名实体以上的主体时，系统级拦截，并将列表顶部“发起评价”全局动作钮剥减触发能力，视觉灰置不可用处理。

## 五、 底座非功能性需求架构说明
- **审计数据合规回溯**：由于与合规要求严密贴合，该功能任一产生生效闭环的评价动作记录，平台数据库级别均要静默强制落库存留执行提交指令发起人的系统账户真实身份与具体到秒的时序操作记录时间戳。
- **系统低碳配置可扩展**：评价指标库设计不要生硬强耦合于页面源码。涉及评价表体系内的各项文字、评分项权重以及维度模块本身应当允许具备权限的操作管理员进入【电子表单中心配置】引擎后段中实现低代码修改扩展及发布新版，适应科室评级策略可能的变化迭代。

## 六、 页面样式要求
本次更新要点（完全采用原生 HTML/CSS 实现，不依赖额外的 js 或 python 文件）：
### 6.1 整体视觉风格 (General Style)
- **设计语言**：标准的 B 端管理系统风格，强调高信息密度与扁平化设计。
- **色调**：
  - **主色调**：蓝色 (#008CFF)，用于顶部导航栏、按钮、页码激活态。
  - **辅助色**：红色（删除/危险操作）、绿色（通过/成功状态标签）、橙色（待处理/实验中状态标签）。
  - **背景色**：页面背景为浅灰色 (#F0F2F5)，容器内容区为白色 (#FFFFFF)。

### 6.2 布局结构 (Layout)
- **顶部栏 (Top Bar)**：
  - 左侧显示系统名称及版本号（如：朗珈试剂耗材管理系统 V1.5.40）。
  - 右侧包含功能图标：消息提示、设置、全屏、锁屏、刷新、多语言切换、用户个人信息。
- **页签栏 (Tab Bar)**：支持多任务切换，当前选中项下方有蓝色高亮条，带有关闭按钮。
- **操作区 (Action Bar)**：
  - 位于列表顶部，背景设为浅灰色 (#F5F5F5) 并带有下边框分割，紧凑压缩纵向视觉高度。
  - 左侧包含平推的四个常用功能按钮：【新增】、【下载模板】、【导入】、【导出】。
  - 右侧为无边距成组的搜索区，包含下拉维度筛选、直接搜索输入框与醒目的橙黄色（#FAAD14）“查询”按钮。

### 6.3 列表与详情抽屉规范 (List & Drawer Specification)
- **卡片式列表 (Card-based List)**：
  - 彻底抛弃传统数据表格，采用区块隔离感强列的流线型白色卡片排布（定高），悬停触发极浅灰 (#FAFAFA) 高亮响应底色。
  - **前置徽标**：左侧统一配备高亮蓝底圆形的企业/楼宇 SVG 抽象图标。
  - **主副信息区**：垂直双行流排布，上层加粗重点显示主体名称，下层补充灰色机构 ID 与各类状态提示标签。
  - **卡片操作栏**：置于卡片尾侧，采用无背景色的纯原生文字链接按钮方案（蓝色表示编辑，红色表示删除，橙色表示评价），保持整体轻量化。
- **状态标签 (Status Tags)**：圆角矩形小垫片，极浅背景色调，边框与文字同色呼应（如绿色代表“资质合规/已启用”，橙色指代“将过期/评价中”）。
- **右侧推拉详情抽屉 (Side Drawer)**：
  - **柔性排版机制**：抽屉锚定于屏幕视口边界右侧，划出时动态推挤主内容列表区的 Flex 宽度（确保绝对不会重叠遮挡列表卡片阅读与操作）。
  - **大尺寸名片模块**：抽屉顶侧左上有用以收缩折叠的 `>>` 交互箭头，页面正上方构筑了全局居中的“发光底圈大尺寸图标 + 机构全称 + 系统编码 + 是否启用标签”的视觉中心 Profile。
  - **单列垂直信息流**：屏弃原本二维栅格，各种档案与资料明细一律转化为单列向下排列，并细分为 `Label(灰色右定宽) + Value(深色占位)` 同行左对齐方式，通过横跨的浅割破线维持不同区块资料的整洁阅读体验。
  - **内容展示范围限制**：此详情侧框仅用于展示供应商的基础档案明细，**不再展示资质附件列表**及**评价记录数据**（相关资料交由专门的编辑弹窗及评价大弹窗承载）。

### 6.4 筛选器与表单 (Filter & Form)
- **输入框/下拉框**：统一的高度（约 32px）。灰白色背景，浅灰色边框，Focus 时变为蓝色边框。占位符文字颜色为浅灰色。
- **复选框 (Checkbox)**：标准正方形蓝色勾选框，支持表头全选。

### 6.5 分页组件 (Pagination)
- 居中或居右对齐。
- 显示总条数、每页显示记录数下拉框（如：50条/页）、页码切换按钮、跳转页输入框。
