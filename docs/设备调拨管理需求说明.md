# 设备调拨管理需求说明

## 1. 变更院区（调拨）弹窗

在【设备档案维护】主界面顶部操作栏点击 **【变更院区】** 唤起该弹窗（宽度 460px，弹窗标题“变更院区”居中排布）。
已调出禁用的设备，该按钮禁用置灰不可点击。

### 1.1 弹窗字段信息
- **`*调入院区`**：下拉单选框，必填，可选项为东院区、西院区、南院区（自动排除当前所属院区），默认选中首个目标院区。
- **`*调出时间`**：日期选择器，必填，不需要时分秒，默认取当前系统日期（`YYYY-MM-DD`）。
- **`备注`**：单行文本输入框，选填，输入调拨原因或说明，默认空（placeholder：“输入调拨原因或备注说明（选填）”）。

### 1.2 操作按钮与流转逻辑
- **【确定】**：
  1. 校验必填项（调入院区、调出时间）；
  2. 校验通过后，调出端（原院区）该设备状态变更为“已禁用”，锁定不可恢复，原记录在原院区封存；
  3. 调入端（目标院区）自动生成一条状态为“未启用”的对应新设备，工作台重置为“未分配工作台”；
  4. 向【设备调拨查询】写入一条不可篡改的历史调拨记录；
  5. 关闭弹窗并提示“设备调拨成功”。
- **【取消esc】**：关闭弹窗，不保存任何修改。


## 2. 设备调拨查询（主列表）

用于查看设备调拨历史流水的只读台账页面。

### 2.1 顶部检索区
- **综合搜索框**：单行文本输入框，placeholder：“输入设备编号/名称/规格型号”，支持模糊检索，按 Enter 键即查，清空回车恢复全量。
- **【查询】**：纯蓝按钮，点击按输入关键字检索调拨记录。

### 2.2 列表展示与规则
- **样式与排版**：标准主列表样式，单行行高严格为 **34px**；不设操作列与查看入口，防误操作与防篡改。
- **排序规则**：默认按 **调出时间倒序展示**，最新调出的记录在最前面。
- **展示字段**：
  - **序号**：递增数字居中展示。
  - **设备名称**：居左展示。
  - **设备编号**：等宽字体居中展示。
  - **规格型号**：居中展示，无内容显示“-”。
  - **调出院区**：居中展示。
  - **调入院区**：居中展示。
  - **调出时间**：纯日期点格式展示（`YYYY-MM-DD`，无时分秒），等宽居中。
  - **经办人**：居中展示。
  - **备注**：居左展示，无内容显示“-”。
