# 设备档案及授权管理需求说明

## 一、 业务背景与总体架构

为满足 CNAS（ISO 15189）医学实验室认可准则及药监局飞检对设备全生命周期管理、“三证”合规溯源、人员操作资质授权及性能验证（室内比对、设备验证、室间质评）的要求，本系统（朗珈设备管理系统 V1.3.51）在【设备】模块下的【设备档案】二级菜单中，构建了以**【设备档案维护】**（日常建档、编辑、授权分配、记录维护及比对发起）与**【设备档案查看】**（全生命周期一页式只读合规总览）为核心的双视图协同管理体系。

左侧二级导航菜单【设备档案】包含五个子项：
- **设备列表清单**：传统宽表形式的设备台账列表与字段配置导出。
- **设备档案维护**：三栏式综合管理工作台（分类导航 + 设备卡片列表 + 三分区模块化档案编辑与抽屉式业务管理）。
- **设备档案查看**：两栏式全维度档案穿透查询页（设备卡片列表 + 三分区档案详情与关联业务折叠模块）。
- **设备附件查询**：全科设备关联资质与说明书附件的集中检索。
- **设备调拨查询**：全屏跨院区流转只读审计台账（详见 [设备调拨管理需求说明.md](file:///d:/lee/ai应用文档/设备管理/docs/设备调拨管理需求说明.md)）。

## 二、 全局核心重构规范（【维护页】与【查看页】通用）

为解决原页面字段平铺堆砌、读写视图结构割裂以及医疗器械“三证”监管信息缺失的问题，【设备档案维护】与【设备档案查看】统一实施以下三项全局重构：

### 2.1 档案内容分区：统一采用浅蓝底可折叠面板（`∨ 分区名称`）
摒弃平铺直叙的字段堆砌与多套视觉样式混用，参考系统统一面板规范，【设备档案维护】与【设备档案查看】的档案信息区均统一采用**浅蓝底可折叠面板（`∨ 分区名称`）**进行模块化展示，保持编辑态与只读态读写逻辑 100% 一致，并按业务建档先后逻辑依次排布、支持按需展开/收起：

1. **折叠模块一：`∨ 基础信息`**
   - **核心物理与院内归属**：`* 设备名称`、`固定资产编码`、`* 所属工作台`、`设备编号`、`出厂编号`、`合同编号`、`型号`、`所属实验室`、`购置部门`、`设备原值(价格)`、`设备位置`、`说明书存放处`、`管理员`。
   - **生命周期与状态属性**：`生产日期`、`购买日期`、`启用日期`、`状态`（已启用/已停用/已报废）、`使用期限（年）`、`入院状态`、`特殊设备（是/否）`、`最后修改时间`（查看页展示）。
   - **导入标识行**：末行通栏展示 `导入标识`。
2. **折叠模块二：`∨ 资质与厂商信息`**
   - **厂商与联络信息**：将原散落在基础表单中的 `生产厂家`、`供应商`、`联系人`、`联系电话` 集中收纳至此模块。
   - **新增“三证”合规管理字段**：`器械管理类别`、`医疗器械注册证号/备案凭证号`（含快捷预览交互）、`证件效期截至`（含红绿灯效期预警）。
3. **折叠模块三：`∨ 性能与质控参数`**
   - **计量与阈值参数**：`校准/检定频率`、`最后校准时间`（查看页展示）、`阈值1`、`阈值2`。
   - **通栏长文本区（`span="24"`）**：`性能参数及用途`（多行文本域）、`备注`、`备注1`、`备注2` 均采用整行通栏排布，避免挤压在多列网格中影响输入与阅读体验。
4. **折叠模块四：`∨ 验收信息`（含首行开关与三级子分级）**
   - **内部首行（开关与归口部门）**：第一行左占1列放置 `是否需要验收（是/否）` 胶囊开关，右占2列放置 `验收部门`。当 `是否需要验收 = 是` 时展开下方三级验收详情；切换为 `否` 时自动收起下方三级子分级，仅保留首行开关状态。
   - **子分级样式与顺序**：内部无背景色块填充，采用**左侧圆角蓝色竖条标签（`▎`）**标识子级标题（字号 `12px` 小于父级标题），严格按照参考截图顺序依次展示 **`▎安装确认`** $\rightarrow$ **`▎功能验证`** $\rightarrow$ **`▎性能验证`** 三个子分级。
5. **折叠模块五与六：`∨ 质控项设置` 与 `∨ 修正因子设置`**
   - 属性行均由所关联的设备记录模板自动带出（按蓝色下划线模板名称如 `运行记录`、`使用记录`、`校准记录` 分组展示），**无新增按钮，仅支持对已有属性行进行【编辑】配置**（查看页同步只读展示）。

### 2.2 补齐“三证”合规管理字段与红绿灯预警
在“`∨ 资质与厂商信息`”中统一新增以下三个关键监管字段，满足药监局飞检及医疗器械全生命周期合规要求：

| 字段名称 | 控件类型与字典值 | 必填与校验规则 | 视觉与业务联动逻辑 |
| :--- | :--- | :--- | :--- |
| **`* 器械管理类别`** | 下拉单选：<br>`一类` / `二类` / `三类` / `非医疗器械` | **必填（`*`）** | 若选择 `一类/二类/三类`，则右侧“注册证号”与“证件效期”强制必填；若选择 `非医疗器械`，证号与效期自动取消必填星号。 |
| **`* 医疗器械注册证号/备案凭证号`** | 文本框 + 右侧内嵌 **【👁 预览】** 按钮 | 医疗器械类别下**必填（`*`）** | 录入如 `粤深械备20200158号`；点击右侧小眼睛图标直接弹窗预览关联的注册证/备案凭证扫描件。 |
| **`* 证件效期截至`** | 日期选择器（`YYYY-MM-DD`）+ **红绿灯预警徽标** | 医疗器械类别下**必填（`*`）** | **底层红绿灯效期预警逻辑**：<br>• 距到期 `> 30天`：绿色圆点 + `正常有效`<br>• 距到期 `1 ~ 30天`：橙黄圆点 + `即将到期（剩余X天）`<br>• `已到期（< 当天）`：红色圆点 + 红色加粗文字 `已过期` |

### 2.3 “证照快捷联动预览”交互
- **触发位置**：紧贴 `医疗器械注册证号/备案凭证号` 输入框（维护页）或文本值（查看页）右侧，提供带小眼睛图标的 **【👁 证照预览】** 快捷按钮。
- **联动机制**：点击后，系统自动检索当前设备“设备附件”列表中文件类型为 `医疗器械注册证/备案凭证` 的最新附件（如《达科为第一类医疗器械生产备案凭证.pdf》），并直接唤起居中 **证照扫描件预览弹窗**（展示证照高清扫描页、文件名称、效期状态及下载入口），免去用户滚动到底部或切换抽屉查找附件的繁琐操作。

## 三、 【设备档案维护】页面（表单编辑页）需求说明

【设备档案维护】采用**左一（设备分类栏）+ 左二（设备卡片列表）+ 右侧（可折叠分区档案编辑区及侧滑抽屉）**的三栏联动布局。

> 基础布局参考截图：[设备档案维护.png](file:///d:/lee/ai应用文档/设备管理/references/设备档案/设备档案维护.png)

### 3.1 左一栏：设备分类栏
1. **顶部标题与检索**：标题为“设备”，右侧紧跟“类型名称”模糊检索输入框。
2. **模板与数据操作条**：并列提供 **【下载模板】**（橙色）、**【导入】**（蓝色）、**【刷新】**（蓝色）。
3. **分类统计列表**：纵向展示设备分类及台数（如 `全部(74)`、`达科为染色机(1)`），环境关联设备分类带绿色圆形 **“环”** 字标识。

### 3.2 左二栏：设备卡片列表
1. **顶部核心操作栏**：并列提供 **【新增授权】**（绿色）、**【新增】**（蓝色）、**【打印】**（橙色）。
2. **批量选择与联合查询栏**：`全选` 复选框 + `已选: N`；下方为 `工作台` 下拉框 + `名称/编号/资产编码` 搜索框 + **【查询】** 按钮。
3. **设备卡片流**：展示设备名称、状态标签（`已启用`/`已停用`/`已报废`）、设备类型、固定资产编码、设备编号、管理员、工作台。选中卡片高亮浅蓝背景与右上角蓝色三角勾选角标。

### 3.3 右侧主面板：可折叠分区档案表单编辑区
顶部标题栏展示当前设备名称，右侧并列放置业务按钮：**【查看设备记录】**（蓝）、**【附件管理】**（蓝）、**【设备授权记录】**（橙黄）、**【内部比对】**（蓝框）。下方主体内容按浅蓝底可折叠面板依次排布：

1. **顶部设备摘要横幅**：展示设备缩略图、设备名称、状态标签、`固定资产编码`、`工作台`、`所属实验室`。
2. **`∨ 基础信息`**
   - 包含核心物理与院内归属字段（`* 设备名称`、`固定资产编码`、`* 所属工作台`、`设备编号`、`出厂编号`、`合同编号`、`型号`、`所属实验室`、`购置部门`、`设备原值(价格)`、`生产日期`、`购买日期`、`启用日期`、`状态`、`设备位置`、`说明书存放处`、`管理员`、`使用期限(年)`、`入院状态`、`特殊设备`）。
   - 末行通栏展示 `导入标识`。
3. **`∨ 资质与厂商信息`**
   - **第一行（厂商联络）**：`生产厂家`、`供应商`、`联系人`、`联系电话`（归拢展示）。
   - **第二行（三证合规）**：`* 器械管理类别`、`* 医疗器械注册证号/备案凭证号`（附带 **【👁 证照预览】** 按钮）、`* 证件效期截至`（实时计算并显示红绿灯效期徽标）。
   - **保存强校验**：点击【保存】时，若器械管理类别非“非医疗器械”且未填写注册证号或效期截至日期，表单自动标红拦截并提示补齐合规三证信息。
4. **`∨ 性能与质控参数`**
   - **第一行**：`校准/检定频率`、`阈值1`、`阈值2`。
   - **整行通栏区（`span="24"`）**：`性能参数及用途`（多行文本域）、`备注`、`备注1`、`备注2` 均独占整行宽度。
5. **`∨ 验收信息`（首行放置验收开关与验收部门，子级标题带左侧蓝色竖条标签）**
   - **内部第一行**：`是否需要验收`（胶囊开关：是/否）+ `验收部门`（占2列）。开启 `是` 时展示下方三个子分级，关闭 `否` 时隐藏下方三个子分级。
   - **子分级一：`▎安装确认`**：
     - 第一行（3列）：`设备到货状态`（下拉单选）、`安装位置确认`（下拉单选）、`水电环境确认`（下拉单选）；
     - 第二行（整行通栏 `span="24"`）：`安装确认结论`（多行文本域）；
     - 第三行（前2列）：`确认人`（文本框）、`确认日期`（日期选择框）。
   - **子分级二：`▎功能验证`**：
     - 第一行（3列）：`开机自检`（下拉单选）、`各模块功能测试`（下拉单选）、`软件版本确认`（文本框）；
     - 第二行（整行通栏 `span="24"`）：`功能验收记录`（多行文本域）；
     - 第三行（前2列）：`确认人`（文本框）、`确认日期`（日期选择框）。
   - **子分级三：`▎性能验证`**：
     - 第一行（3列）：`验证方式`（下拉单选）、`验证批次`（文本框）、`验证结论`（下拉单选）；
     - 第二行（整行通栏 `span="24"`）：`性能验证报告`（多行文本域）；
     - 第三行（3列）：`验证人`（文本框）、`验证日期`（日期选择框）、`* 验收结果`（**必填**，下拉单选：通过验证/不通过）。
   - **底部操作栏**：右对齐放置档案主表单 **【保存】** 按钮。
6. **`∨ 质控项设置`**：无新增按钮，表格列含 `记录属性`、`属性编码`、`输入框类型`、`合格值枚举`、`最小阈值`、`最大阈值`、`操作`；内部按记录模板（如蓝色下划线分组行 `运行记录`、`使用记录`）归类展示，仅提供行级 **【编辑】** 按钮修改阈值与枚举。
7. **`∨ 修正因子设置`**：无新增按钮，表格列含 `记录属性`、`属性编码`、`数值`、`操作`；内部按记录模板（如蓝色下划线分组行 `校准记录`）归类展示，仅提供行级 **【编辑】** 按钮修改修正因子数值。

### 3.4 右侧三大滑出抽屉（Drawer）
1. **【设备记录】抽屉**（参考 [设备档案维护-记录详情.png](file:///d:/lee/ai应用文档/设备管理/references/设备档案/设备档案维护-记录详情.png)）：含 `全部记录`、`日维护记录`、`故障记录`、`维修记录`、`校准记录`、`周维护记录`、`按需保养记录` 7 个子页签，支持月份打印、多维检索与导出。
2. **【附件管理】抽屉**（参考 [设备档案维护-附件详情.png](file:///d:/lee/ai应用文档/设备管理/references/设备档案/设备档案维护-附件详情.png)）：支持【选择文件】上传，行内切换 `文件类型`（说明书、企业法人营业执照、医疗器械注册证/备案凭证、产品合格证、设备验收报告/单）、设置有效期起止时间，提供【下载】、【预览】、【删除】。
3. **【设备人员授权记录】抽屉**（参考 [设备档案维护-人员授权详情.png](file:///d:/lee/ai应用文档/设备管理/references/设备档案/设备档案维护-人员授权详情.png)）：支持【新增授权详情】、按姓名检索，展示授权类型、有效期、附件数量，支持行级【注销】与【编辑】。

## 四、 【设备档案查看（查询）】页面（详情展示页）需求说明

【设备档案查看】采用**左侧（设备列表卡片区）+ 右侧（全景可折叠面板区）**的两栏布局。针对详情页的数据完整性与业务融合要求，进行如下专项设计：

> 基础布局参考截图：[设备档案查询.png](file:///d:/lee/ai应用文档/设备管理/references/设备档案/设备档案查询.png)

### 4.1 档案信息可折叠面板：与维护页 100% 同步结构并补齐遗漏数据
在右侧面板顶部设备摘要横幅下方，依次排布与编辑页完全一致的 6 个档案可折叠面板：

1. **`∨ 基础信息`**：三列只读网格展示核心物理身份、院内资产归属、使用状态及系统衍生字段（`最后修改时间`、`导入标识`）。
2. **`∨ 资质与厂商信息`**：集中展示 `生产厂家`、`供应商`、`联系人`、`联系电话` 及医疗器械“三证”字段（含 **【👁 预览注册证/备案凭证扫描件】** 按钮与红绿灯效期徽标）。
3. **`∨ 性能与质控参数`**：展示 `校准/检定频率`、`最后校准时间`、`阈值1 / 阈值2`，并以整行通栏（`span="24"`）只读展示 `性能参数及用途`、`备注`、`备注1`、`备注2`。
4. **`∨ 验收信息`**：内部第一行展示 `是否需要验收` 与 `验收部门`，下方按 **`▎安装确认`** $\rightarrow$ **`▎功能验证`** $\rightarrow$ **`▎性能验证`** 三个子级完整展示只读验收记录与最终 `验收结果`。
5. **`∨ 质控项设置`（高优补齐）**：按记录模板分组（如 `运行记录`、`使用记录`）只读展示 `记录属性`、`属性编码`、`输入框类型`、`合格值枚举`、`最小阈值`、`最大阈值`。
6. **`∨ 修正因子设置`（高优补齐）**：按记录模板分组（如 `校准记录`）只读展示 `记录属性`、`属性编码`、`数值`。

### 4.2 底部关联业务折叠模块（Accordion）
在上方 6 个档案折叠面板下方，依次纵向排布 7 个生命周期业务记录折叠面板：
1. **设备附件 (`∨ 设备附件`)**：只读展示文件类型、文件名称、文件大小、文件后缀、有效期起止时间，操作列提供【下载】与【预览】。
2. **设备授权 (`∨ 设备授权`)**：支持按姓名查询，只读展示序号、姓名、状态、授权类型、有效期、附件数量、最后操作人。
3. **设备记录 (`∨ 设备记录`)**：含 7 类维护/故障/维修/校准子页签、月份打印、复合条件查询与导出。
4. **电子表单 (`∨ 电子表单`)**：支持按标签、全选、分组、记录名称查询关联审批表单。
5. **室内比对记录 (`∨ 室内比对记录`)**：支持按检测方法/项目、差异因素、创建时间查询，并支持唤起【关联分子实验记录】弹窗。
6. **设备验证记录 (`∨ 设备验证记录`)**：含 `故障验证`、`校准验证` 双子页签，展示校验/维修结果、验证方法、验证结论、验证人等。
7. **室间质评 (`∨ 室间质评`)**：支持按质评计划名称、项目名称、质评类型、质评结果检索室间质评记录。
