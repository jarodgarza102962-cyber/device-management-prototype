# 人员档案系统需求说明

## 一、 需求背景
为了满足 CNAS/ISO 15189 病理科认可合规性要求，科室人员档案必须能够追溯其资质与设备操作权限。本项目旨在升级人员档案系统（HRP/人事系统），丰富基础个人档案与业务记录（培训、考核等），并特别在“档案信息”区域中，实时回显该人员在“设备管理系统”中的授权记录，实现电子化档案闭环，方便内审与现场检查。

## 二、 核心功能需求

### 2.1 档案检索与筛选（左侧面板）
- **多维度搜索**： 支持按部门、专业组、在职情况、姓名、文化程度、职称、政治面貌、年龄段、分组等字段进行组合查询。
- **列表展示**： 以分页表格形式展示人员基本信息（工号、档案编号、姓名、用户名、性别、年龄等）。
- **联动交互**： 点击列表中的某一行，右侧详情面板需实时切换至对应人员的详细档案。
- **数据导出**： 提供“导出人员汇总信息”功能，支持将检索后的结果集导出为 Excel 文件。

### 2.2 个人档案详情（右侧面板）
右侧面板为核心信息展示区，采用多层级折叠面板和标签页（Tabs）设计：
- **A. 顶部个人摘要**
  展示照片（支持加载状态提示）、姓名、在职状态。
- **B. 基础信息（折叠面板）**
  展示静态背景资料：档案编号、工号、性别、联系方式、出生日期、身份证号、籍贯、民族、最高学位、政治面貌等。
- **C. 工作信息（折叠面板）**
  展示职务属性：所在部门、专业组、岗位（如：主任授权签字人）、技术职称（如：主治医师）、在职情况、入职/进修开始日期等。
- **D. 动态业务记录（标签页组）**
  通过标签页（Tabs）切换查看该人员的关联业务数据：
  - **人员信息**： 默认主页。
  - **培训记录**： 显示参与培训的次数及详情。
  - **考核记录**： 绩效评价及考核结果。
  - **会议/加班/电子记录**： 相关的考勤与行政记录。

### 2.3 档案信息深度管理（底部 Tab 区域）
在“档案信息”大类下，进一步细分资质与合规性管理：
- **资质附件管理**：
  - 展示资质名称（如：执业医师证）、附件数量。
  - **效期监控**： 记录“有效期开始/结束时间”。
  - **状态预警**： 使用颜色标识：黄色代表“快到期资质”，红色代表“已到期资质”。
  - 支持设置“是否提醒”。
  - **操作**： 点击“查看”可调取附件预览。
- **其他相关标签**： 体检报告、继续教育、工作和学习简历及其他材料、资质授权。

### 2.4 设备授权查看（新增特化标签）
延续现有“资质附件”页签的表格布局，新增“设备授权 (N)”Tab（其中 N 为该人员关联的设备授权记录总条数）：
- **数据回显逻辑**：
  - **数据来源**：实时接口调用（从设备管理系统获取最新数据全部历史记录，不进行物理隐藏）。
  - **排序规则**：1. 按状态排序（生效中 > 即将过期 > 已过期）；2. 同状态下按“授权开始日期”倒序排列。
- **字段展示与视觉**：
  - 设备名称：设备名（设备状态），如染色封片机（<span style="color:green;">已启用</span>）。
  - 设备编号：BL-EQ-2024005。
  - 授权权限：独立操作 / 维护保养 / 管理权限等。
  - 授权起止日期：已过期（红色），即将过期（黄色≤30天），正常（黑色）。
  - 最后修改人：李明（管理员）。
- **跨系统跳转**：操作列提供“查看详情”按钮，点击后系统嵌套（iFrame或弹窗）展示设备系统对应的详情页，需处理 SSO 认证避免反复登录。

## 三、 交互与 UI 规则
- **布局比例**：左侧列表与右侧详情支持自适应分布，确保在不同分辨率下信息密度合理。
- **视觉反馈**：
  - 选中列表行需有高亮状态（蓝色背景）。
  - 对于过期资质（或设备授权），日期文字需变红以示警告。
- **导航辅助**：顶部面包屑导航应清晰显示当前位置（例如：人员首页 > 人员信息首页）。

## 四、 非功能性需求
- **实时性**： 每次切换至“设备授权”Tab 时，前端需发起异步请求，确保数据为设备系统中的最新快照。
- **兼容性**： 嵌套页面需适配档案系统的弹窗尺寸，确保无多余滚动条。

## 五、 页面样式要求
本次更新要点（采用原生 HTML/CSS 实现）：
### 5.1 整体视觉风格 (General Style)
- **设计语言**：标准的 B 端管理系统风格，强调高信息密度与扁平化设计。
- **色调**：
  - 主色调：蓝色 (#008CFF)，用于顶部导航栏、按钮、页码激活态。
  - 辅助色：红色（删除/危险操作）、绿色（通过/成功状态标签）、橙色（待处理/实验中状态标签）。
  - 背景色：页面背景为浅灰色 (#F0F2F5)，容器内容区为白色 (#FFFFFF)。

### 5.2 布局结构 (Layout)
- **顶部栏 (Top Bar)**：左侧显示系统名称及版本号；右侧包含功能图标。
- **页签栏 (Tab Bar)**：支持多任务切换，当前选中项下方有蓝色高亮条。
- **操作区 (Action Bar)**：紧贴页签下方，包含检索与导出。

### 5.3 表格样式规范 (Table Specification)
- **边框与分割**：采用细边框网格布局，横向与纵向均有淡灰色分割线。
- **表头 (Table Header)**：背景色为极浅灰色 (#FAFAFA)。
- **行高与内边距**：紧凑型设计，行高约 40px，Cell 内边距约 8px。
- **状态标签 (Status Tags)**：圆角矩形，背景色极浅，边框与文字颜色一致。

### 5.4 筛选器与表单 (Filter & Form)
- **输入框/下拉框**：统一高度（约 32px）。灰白色背景，浅灰色边框，Focus 时变为蓝色边框。

### 5.5 分页组件 (Pagination)
- **对齐方式**：居右对齐。
- **内容**：显示总条数、每页显示记录数下拉框（如：50条/页）、页码切换按钮、跳转页输入框。
